# 外国文学1 · 猫猫抽题本

第一章「上古文学」分为填空、名词解释、简答和论述四个题型。选择题型后可以随时展开或折叠答案。点「记得」后，这道题在本轮过关；点「不记得」后，它会留在本轮继续抽。四个题型分别保存进度，完成某一题型后可以开始它的新一轮。

手机和电脑直接打开[猫猫抽题本](https://qianc9636-ship-it.github.io/foreign-literature-study/)，会自动接续相同的学习进度。所有访客共用这一份进度，每个人答题都会影响其他设备。看到「云端已同步」后，就可以换设备接着练。

每次答题会自动保存轮次、已记得的题和当前题目。第一次连接会合并浏览器里已经有的记录；同一轮两端记得的题都保留，某一端已开始新一轮时接续较高轮次。断网可以继续练，保持页面打开或下次打开网站时会自动补传。下载的离线 HTML 在当前浏览器独立保存进度。

## 用 Word 更新本机题库

1. 在第一章 Word 的副本上编辑，保存为 `.docx`。保留四个题型标题。新增题目时复制相同题型已有的题干和答案段落，再改文字，可保留原有样式和多段答案结构。
2. 打开网站的「题库管理」，选择更新后的 Word。核对预览里的四类题数，再点「确认使用这份题库」。
3. 回到抽题页即可使用新题库。Word 由当前浏览器读取，导入只影响当前设备和浏览器。

## 让手机和电脑都能用上新版题库

1. 在已经导入新版 Word 的设备上打开「题库管理」，点「下载 bank.js」。
2. 登录 GitHub，打开[网站仓库](https://github.com/qianc9636-ship-it/foreign-literature-study)，在仓库首页选择 **Add file → Upload files**，上传刚下载的 `bank.js`。文件名保持为 `bank.js`，放在与 `index.html` 同一层。
3. 选择 **Commit changes** 提交到发布分支，等仓库的 Pages 部署完成。在其他设备重新打开或刷新原网址，即可读取新版公开题库。如需手动切换，打开「题库管理」，点「使用网站版」并确认。
