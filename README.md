# 外国文学1 · 猫猫抽题本

选择第一章「上古文学」、第二章「中古文学」、第三章「14—16世纪文学」、第四章「17世纪文学」或第五章「18世纪文学」可以分章复习。选「全部章节」后，从所有章节合在一起的填空、名词解释、简答或论述题中任选一类随机练习。在每个范围里，四种题型独立计轮。点「记得」后该题本轮过关，点「不记得」后仍在本轮继续抽。题目右上角的抽到次数跨范围累计。

题目保留 Word 中的重点标记。「老师重点」用浅蓝底色显示，与「课堂测验考过」分别标注。

手机和电脑直接打开[猫猫抽题本](https://qianc9636-ship-it.github.io/foreign-literature-study/)，会自动接续相同的学习进度。所有访客共用这一份进度，每个人答题都会影响其他设备。看到「云端已同步」后，就可以换设备接着练。

每次答题会自动保存轮次、已记得的题和当前题目。第一次连接会合并浏览器里已经有的记录；同一轮两端记得的题都保留，某一端已开始新一轮时接续较高轮次。断网可以继续练，保持页面打开或下次打开网站时会自动补传。下载的离线 HTML 在当前浏览器独立保存进度。

## 用 Word 更新本机题库

1. 在对应章节的 Word 副本上编辑，保存为 `.docx`。保留四个题型标题。新增题目时复制相同题型已有的题干和答案段落，再改文字，可保留原有样式和多段答案结构。
2. 打开网站的「题库管理」，选好「管理章节」，再选择更新后的 Word。核对预览里的四类题数，再点「确认使用这份题库」。
3. 回到抽题页即可使用新题库。Word 由当前浏览器读取，导入只影响当前设备和浏览器。

## 让手机和电脑都能用上新版题库

1. 在已经导入新版 Word 的设备上打开「题库管理」，选择对应章节，下载题库文件。第一章使用 `bank.js`，第二至第五章分别使用 `bank-ch2.js`、`bank-ch3.js`、`bank-ch4.js`、`bank-ch5.js`。
2. 登录 GitHub，打开[网站仓库](https://github.com/qianc9636-ship-it/foreign-literature-study)，选择 **Add file → Upload files**，将下载的文件按原名上传，与 `index.html` 放在同一层。
3. 选择 **Commit changes** 提交到发布分支，等仓库的 Pages 部署完成。在其他设备重新打开或刷新原网址，即可读取新版公开题库。如需手动切换，打开「题库管理」，点「使用网站版」并确认。
